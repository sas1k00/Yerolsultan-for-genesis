# Тот день — описание

**Идея.** Галерея хранит, как выглядел день, но не как он ощущался. «Тот день» превращает запись, фото и песню в страницу дневника, где ощущение дня видно в приёме, цвете, ритме, фактуре и голосе. Каждая страница лежит в папке с названием, которое система придумывает по записи: «Ночь в офисе перед сдачей», «Поездка в Рим с одногруппниками».

**Аудитория.** Люди 16–35 лет, которые много фотографируют и мало вспоминают: студенты, пары, путешественники. Две минуты, чтобы «закрыть день» и через год вернуться в него.

**Как текст, фото и музыка влияют на результат.** Без ИИ: только явные правила, каждое объяснено под страницей («Почему день выглядит так»).

- **Текст** (русский, казахский, смешанный) → настроение и энергия по ~330 основам слов с учётом «не», «очень», «немного». Правило «пик и финал» (Канеман): конец дня, фраза после «но / а потом» и самый сильный момент весят больше. Время суток и погода дают фактуру, место и люди — название, слова человека — подпись.
- **Фото** → палитра дня из самих фото, окрашенная настроением. Главное на фото (люди, детали) не обрезается: если не помещается, края заполняет размытая копия того же фото.
- **Музыка** → темп, доля и лад из звука (FFT, профили Крумхансла) или, для ссылки, два касания человека («спокойная / энергичная», «светлая / грустная»). Кадры меняются точно в долю, формы пульсируют на каждой доле. Звучит момент песни, похожий на припев (можно выбрать на слух). Медленная минорная песня даёт больше воздуха, старая — плёночное зерно.

Настроение = 55 % текст + 30 % музыка + 15 % фото; энергия = 35 % + 45 % + 20 %. Если в дне два чувства или песня спорит с текстом, к главному приёму добавляется второй: каждый 3–5-й кадр показывает тот же момент другим чувством.

**Визуальная система.**
*Постоянно:* формат 9:16, бумага, дата (IBM Plex Mono), окно фото с бумажными уголками, рукописное название (Caveat), строка песни, «печать дня» — точка настроения и энергии.
*Меняется:* один из четырёх приёмов (Моне, Кандинский, Матисс, японское «ма» — см. «Художественные приёмы»), обработка фото, ритм и переходы, пустое пространство, зерно, погода, шрифт подписи, подача голоса.

**Названия и голос.** Названия в одной интонации: без глагола, 3–7 слов. Голос рассказчика один: спокойный день он читает медленнее и ниже, насыщенный — быстрее.

**Технически.** Веб-приложение без сервера (Canvas 2D, Web Audio, Web Speech, IndexedDB), 97 автотестов. Запись и фото остаются в браузере; наружу уходит только ссылка и название песни.
